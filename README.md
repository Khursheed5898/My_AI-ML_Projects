## 🚀 How to Run Notebooks Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Khursheed5898/My_AI-ML_Projects.git
   cd My_AI-ML_Projects
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scriptsctivate
   ```

3. **Install common AI/ML libraries:**
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter notebook
   ```

4. **Launch Jupyter:**
   ```bash
   jupyter notebook
   ```
